    How I got here

    The quiet

    The nursery used to be so quiet. Ugh. Pip lay awake listening to nothing, and nothing is LOUD. Down the lane, Wobbles the ghost couldn’t sleep either, because Wobbles is scared of the dark. Yes, a ghost. We don’t talk about it.

    The first lullaby

    In an attic, Pip found a dusty music box with one key and five notes. Pip wound it up. Plink, plonk, plink. Wobbles stopped shaking. Every little ghost on the street yawned at once. Pip did a victory wiggle and fell off the cloud.

    The job

    The Midnight Nursery hired Pip that very night. Now Pip builds dreams: lullabies, nightlights, bedtime tales. Wobbles tests everything and screams at the scary ones, which is very helpful. Pip is still a little clumsy. Pip is still giggling.
